# Diabetes Information Website

## Description
This project is a static website designed to provide information about diabetes, including symptoms, prevention, and management. It also features an interactive modal-based self-assessment test to help users evaluate potential risk factors.

## Features
- Informational content about diabetes  
- Sections covering symptoms, causes, and prevention  
- Interactive modal test for basic self-assessment  
- Responsive and user-friendly interface  

## Installation
No installation is required.

## Usage
To view the website:

1. Upload all project files to a web server and navigate to the root directory, **or**  
2. Open the `index.html` file in a web browser  

## Configuration
No configuration is required. Content and questions for the modal test can be updated within the source files.
